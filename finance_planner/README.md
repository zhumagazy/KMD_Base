# 💰 Финансовый план 2026–2030

Excel-планер доходов и расходов: план/факт по месяцам и годам, хотелки, справочник.

**Файл:** `Финансовый_план_2026-2030.xlsx` (открывается в Excel / Google Таблицах / Numbers).
Пересобрать: `python finance_planner/build_planner.py` (нужен `openpyxl`).

Цвет вкладок: 🟢 зелёный — витрины (только смотреть), 🔴 красный — технические листы (ввод и настройка).

| Лист | Что делает | Ввод? |
|---|---|---|
| 🏠 Главная | KPI за весь период и за выбранный месяц (выпадающие год/месяц в H4:I4), прогресс хотелок, графики, легенда | — |
| 💸 Расходы | Год, месяц, статья, категория, приоритет, **ПЛАН** / **ФАКТ**, статус | ✍️ |
| 💰 Доходы | Год, месяц, источник, тип (ЗП, проект, разовая услуга…), **ПЛАН** / **ФАКТ**, статус | ✍️ |
| 📅 По месяцам | 60 месяцев: доход/расход/остаток план vs факт, накопительный итог, 3 линейных графика | — |
| 📊 По годам | Итоги по годам, норма сбережений, расходы по категориям × годы, 2 графика | — |
| ✨ Хотелки | Автосписок трат с категориями, отмеченными «Да» в справочнике | — |
| 📚 Справочник | Источник всех выпадающих списков: статьи, категории, типы дохода, статусы | ✍️ |

**План vs факт:** синие колонки — план, зелёные — факт.
**Зачёркивание:** статус «✅ Выполнено» / «✅ Получено» зачёркивает строку и хотелку в списке.
