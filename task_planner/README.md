# ✅ Задачи и календарь 2026–2030

Excel-задачник: задачи с отметкой выполнения, расписание по времени, календарь месяца и итоги.

**Файл:** `Задачник_2026-2030.xlsx`. Пересобрать: `python task_planner/build_tasks.py` (нужен `openpyxl`).

Цвет вкладок: 🟢 зелёный — витрины (смотреть), 🔴 красный — технические (ввод).

| Лист | Что делает | Ввод? |
|---|---|---|
| 🏠 Главная | Сводка, список «Сегодня», просроченные задачи, навигация, график | — |
| 📅 Календарь | Сетка месяца Пн–Вс; в каждом дне — дела по времени и задачи по сроку (до 6 строк + «… ещё N») | год/месяц |
| ✅ Задачи | Задача, группа, категория, приоритет, срок, статус, дата выполнения | ✍️ |
| 🕘 План дня | Дата, начало, конец, дело, группа, категория, связанная задача, статус; длительность и пересечения — авто | ✍️ |
| 📊 Итоги | По статусам, группам занятий, категориям, приоритетам + 2 диаграммы | — |
| 🗓 По месяцам | 60 месяцев: задачи план/выполнено, просрочки, дела и часы + 2 линейных графика | — |
| 📚 Справочник | Группы занятий, категории, статусы, приоритеты | ✍️ |

Значки в календаре: ⏰ дело, ☐ задача, ✔ сделано (зачёркнуто), ❗ просрочено, ✖ пропущено, 🔥 высокий приоритет.
